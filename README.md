
## 制作アプリのタイトル ##
 魔王をじゃんけんで倒そう！
## 制作アプリの説明 ##
勇者になったつもりで魔王とじゃんけんをしてモンスターを仲間にしながら魔王を倒していくゲームです！
## 工夫した点・こだわった点 ##
なんといってもゲーム性を持たせるためにHPをいくつにするか攻撃力をいくつにするかの計算をするのに時間がすごくかかりました。
あまりにも強すぎると飽きてしまうのでアイテムを増やしてみたりしました！
## 次回トライしたいこと##
